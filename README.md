## 🛠️ Technical Specifications
- **Kernel Type:** Monolithic / Freestanding Zig
- **Architecture:** x86_64 with Ring 3 (User Mode) protection.
- **Graphics:** VESA Linear Framebuffer (1024x768) featuring a dynamic Star Seed Heartbeat pulse.
- **Memory:** Identity-mapped Paging (4-level) with a Physical Memory Manager Bitmap.
- **Interface:** Integrated Ziggy Shell with keyboard scancode mapping and vertical scrolling.
- **I/O:** PS/2 Mouse & Keyboard drivers with IDT interrupt handling.
